Happy path · 2:30

  • หน้าสาธารณะ → วาง S/N ที่ขายแล้ว → ไม่มีชื่อ/เบอร์ผู้ซื้อโผล่
  • login admin → ภาพรวมธุรกิจ → กด 90 วัน ตัวเลขเปลี่ยนจริง
  • ตารางเสี่ยงของขาด → คลิกแถว → เห็น S/N รายชิ้น
  • login branch1 → คลิก S/N → บันทึกขาย → ได้วันหมดประกัน

Edge case · 1:30

  • Admin ขายเองไม่ได้ — ไม่มีเมนู และยิง API ตรงก็ได้ 403
  • คนอนุมัติ PR กับคนขายหน้าร้านต้องแยกกัน
  • ไม่ได้แค่ซ่อนปุ่ม — มี test คุมไว้

AI Usage Disclosure

AI ช่วยอะไร · ทีมตรวจอย่างไร · มีอะไรที่ reject

บันทึก 54 entry · 7 คอลัมน์ตามเกณฑ์10 / 14
ช่วงที่ 4สิ่งที่ reject จาก AI

ไม่เชื่อเพราะอ่านแล้วดูดี แต่เพราะรันแล้ววัด

Rejected ตีความ requirement ผิด

AI เข้าใจว่า "Hardware" คือเครื่องมือช่าง แล้วออกแบบ data model แบบนับจำนวน — ทีมปฏิเสธ ให้ทำใหม่เป็น serialized inventory ซึ่งใช้ตลอดโครงงาน

Rejected test ที่ fail ไม่ได้

AI เขียน test กัน N+1 แล้วบอกว่าผ่าน — เราเอาไปรันกับโค้ดเก่าที่ยังมีบั๊ก แล้วมันไม่ fail เพราะดักฟัง database engine ผิดตัว

test ที่ผ่านโดยไม่มีทาง fail = test ที่ไม่ได้ทดสอบอะไรเลย — บันทึกความผิดพลาดของ AI ไว้ 7 ข้อในเอกสาร ไม่ได้เขียนแต่ด้านที่ดี
ไม่มี password / API key / ข้อมูลจริงเข้า AI — สแกน git history แล้ว11 / 14
